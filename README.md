
# BooksCollector — Тесты

## Описание проекта

Проект содержит класс `BooksCollector` для управления коллекцией книг и набор юнит-тестов для проверки его работы.

## Что протестировано

### 1. Метод `add_new_book` (добавление книги)
-  Проверка добавления книги в коллекцию
-  Проверка, что у новой книги пустой жанр
-  Проверка ограничения длины имени (не более 40 символов)
-  Проверка, что пустое имя не добавляется

### 2. Метод `set_book_genre` (установка жанра)
-  Проверка установки жанра книге
-  Параметризация: проверка всех допустимых жанров (Фантастика, Ужасы, Детективы, Мультфильмы, Комедии)

### 3. Метод `get_books_with_specific_genre` (получение книг по жанру)
-  Проверка возврата списка книг определённого жанра

### 4. Метод `get_books_for_children` (книги для детей)
-  Проверка, что книги с возрастным рейтингом (Ужасы, Детективы) не попадают в список для детей
-  Параметризация: проверка для обоих возрастных жанров

### 5. Метод `add_book_in_favorites` (добавление в избранное)
- Проверка добавления книги в избранное
- Параметризация: проверка добавления нескольких разных книг

### 6. Метод `delete_book_from_favorites` (удаление из избранного)
-  Проверка удаления книги из избранного

### 7. Метод `get_list_of_favorites_books` (получение списка избранного)
-  Проверка возврата полного списка избранных книг

## Использованные технологии

- Python 3
- pytest — фреймворк для тестирования
- Параметризация тестов через `@pytest.mark.parametrize`
